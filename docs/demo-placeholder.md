# Demo recording

This folder is reserved for a short screen recording of the repair loop.

## What to record

1. Run the offline demo:
   ```bash
   python -m self_healing --demo
   ```
2. Show a deliberately broken function, the failing test, the generated diff, and the green suite.
3. Keep it under 30 seconds.

## Tools

- Windows: Xbox Game Bar (`Win + G`) or OBS Studio.
- Convert to GIF with [ScreenToGif](https://www.screentogif.com/) or `ffmpeg`.

Save the final file as `docs/demo.gif` and it will render automatically below.
